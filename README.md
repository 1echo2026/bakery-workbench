# 面包烘焙坊 · 私域运营工作台

网易有道 K12 私域运营实习期间的日常运营工作台，纯静态部署于 GitHub Pages。

## 内容
- 烤炉总览：运营期数、AI 审核提效、覆盖基地、待审核素材
- 真实工具链：奖池拼接台 / 奖品清洗台 / 中奖审核工具 / 采购生成器
- 话术库、KPI 四卡、每周四完整审核流程
- 今日任务提醒（按星期几自动弹出，可勾选完成）

## 技术
React 19 + Vite 8 + TypeScript，构建为纯静态资源，无后端依赖。
数据保存在浏览器 localStorage。

本地预览：`python3 -m http.server 8811`
